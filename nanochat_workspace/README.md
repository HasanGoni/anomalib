## 💡 About nanochat

nanochat is **"The best ChatGPT that $100 can buy"** - a complete, minimal, hackable implementation of an LLM like ChatGPT that includes:

- Full pipeline: Tokenization, pretraining, finetuning, evaluation, inference, and web serving
- Cost-effective: Designed to train on a single 8XH100 node for ~$100-800
- Clean codebase: Single, cohesive, minimal, readable implementation
- Web UI: ChatGPT-like interface to talk to your trained model
